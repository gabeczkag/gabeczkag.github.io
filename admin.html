Dostęp

Wpisz klucz dostępu (AUTH_KEY_OR_PASSWORD), by odblokować panel administratora.

Logowanie

Wpisz token GitHub (zakres repo) konta GabeczkaG, by edytować projekty.

Token pozostaje tylko w tej karcie przeglądarki (sessionStorage) i służy do zapisu przez API GitHuba. Nie używaj na publicznych komputerach i unieważnij token po sesji.
