🔌 xKiro Scanner — Connect

Podłącz repo do xKiro: klucz trafi prosto do secretów Twojego repo jako {randomID}_{name}_xkiroapikey. Bot tylko zapisuje (write-only), nigdy nie pokazuje ani nie loguje klucza.

✅ GitHub App zainstalowana (installation ). Teraz podłącz klucz poniżej.

Krok 1 — Instalacja GitHub App

Jeśli jeszcze nie zainstalowałeś scannera na repo:

Install xKiro Scanner

Po instalacji GitHub wróci na tę stronę z potwierdzeniem.

Krok 2 — Podłącz klucz xKiro

Krok 3 — Użyj secreta w Actions

Po zapisie dostaniesz nazwę secreta, np. a1b2c3d4_prod_xkiroapikey. W workflow użyj:

XKiro_API_KEY: ${{ secrets.A1B2C3D4_PROD_XKIROAPIKEY }}

(nazwy secretów są case-insensitive — skopiuj dokładnie to, co zwróci bot)
